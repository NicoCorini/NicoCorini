# Nicolas Corini

Software engineer in Italy.

At [EDALAB](https://edalab.it), an IoT company, I work on the cloud side of connected
products: the backend devices talk to, the infrastructure it runs on, and the dashboards
people watch them from. MQTT, websockets, APIs, deployments. I started on firmware and
still go back down there when a problem sits close to the hardware.

On the side I build management software for small Italian companies at
[C21](https://www.c21.dev). Most of that work is migration: business rules that have
been running in production for years, moved onto a stack we can keep maintaining.

I'm in the first year of an MSc in Computer Engineering at the University of Verona.
Before that I did a BSc in Bioinformatics, working on genomic sequencing and protein
docking.

## Tools

Mostly TypeScript: React, Fastify, Prisma, PostgreSQL and SQL Server.
C# and .NET on the Windows and mobile side.
C and C++ for firmware.
Docker, GitHub Actions, Playwright.

## Some public work

- **[GlucoTrack](https://github.com/NicoCorini/GlucoTrack)**: telemonitoring for type 2
  diabetes, built for a university exam. .NET Core API, React Native client, and a
  background task that flags missed therapy intakes and out-of-range readings.
- **[Campi Agricoli](https://github.com/CoriMorini)**: another university project, this
  one on field monitoring. LoRa sensor stations in a greenhouse, a C# API, and a React
  dashboard over the readings.
- **[IdleSlayer_Bot](https://github.com/NicoCorini/IdleSlayer_Bot)**: a C++ bot that
  plays an idle game for me. Written in 2024, before I started using coding agents.

Most of my work is in private repositories.
